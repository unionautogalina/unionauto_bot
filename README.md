# 🤖 Бот-визитка Union Auto — инструкция

Бот собирает всё главное из Telegram-канала в понятное меню с кнопками:
о компании, категории техники, путь клиента, акции, кредит/лизинг, наличие,
отзывы, контакты, соцсети и заявка на бесплатный подбор.

---

## 1. Создать бота в Telegram (2 минуты)

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`
2. Имя: `Union Auto | Авто и спецтехника`
3. Username: например `UnionAutoInfoBot` (должен заканчиваться на `bot`)
4. BotFather пришлёт **токен** вида `8123456789:AAF...` — скопируйте его
5. Там же можно задать аватар и описание: `/setuserpic`, `/setdescription`

## 2. Узнать свой Telegram ID (куда придут заявки)

Напишите [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш `id` (числом).
Если заявки нужны в рабочую группу — добавьте бота в группу админом и
возьмите ID группы (начинается с `-100`).

## 3. Заполнить config.py

Откройте `config.py` и подставьте:

```python
BOT_TOKEN = "8123456789:AAF..."     # токен от BotFather  ← ЕДИНСТВЕННОЕ, что осталось
ADMIN_IDS = [123456789]             # ваш id (можно несколько)
```

Всё остальное уже заполнено и подтверждено: телефоны (8-800 и мобильный
8 951 006 80-50), почта unionauto.org@mail.ru, WhatsApp, MAX, Telegram,
адрес Владивостока, 2ГИС, график Пн–Пт 10:00–17:00, Instagram, VK,
YouTube, RUTUBE, сайт и цифры компании.

## 4. Запустить

```bash
pip install -r requirements.txt
python bot.py
```

Бот работает, пока запущен процесс. Для круглосуточной работы — VPS + systemd
(см. п. 6) или любой хостинг ботов.

## 5. Как менять тексты

Все тексты — в файле `texts.py`, обычным русским языком.
Поддерживается разметка: `<b>жирный</b>`, `<i>курсив</i>`, `<a href="...">ссылка</a>`.
Кнопки и их порядок — в `keyboards.py` (функция `main_menu`).
После правок перезапустите бота.

Например, чтобы поменять акцию — правите `PROMO_SOCIAL` в `texts.py`, и всё.

## 6. Автозапуск на сервере (Ubuntu, опционально)

```ini
# /etc/systemd/system/unionauto-bot.service
[Unit]
Description=Union Auto Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/unionauto_bot
ExecStart=/usr/bin/python3 /opt/unionauto_bot/bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now unionauto-bot
```

## 7. Как привязать бота к каналу

- В описании канала добавьте строку: `🤖 Вся информация в боте: @ВашБот`
- Закрепите пост-навигацию со ссылкой на бота
- В кнопку под постами (если используете) добавьте ссылку `https://t.me/ВашБот`

## Что нужно уточнить (осталось 2 пункта)

1. **Сроки действия спецпредложения −50%** — сейчас текст без даты
   («действует сейчас»), при необходимости добавим «до 31.12.2026».
2. **Путь клиента для грузовых/спецтехники не под полную пошлину (ГТД)** —
   когда специалисты дадут детали, допишем в `PATH_TRUCKS` в `texts.py`.
